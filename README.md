# Rexlet 🦖

Rexlet is a personal data hub for turning fragmented everyday data into reliable, structured, and useful information.

The first module is **Rexlet Money**, focused on building a reliable foundation for personal financial data.

> Everything important. One place.

## Status

Early development. Rexlet Money v0.1 is currently focused on transaction ingestion, validation, and establishing a reliable financial data foundation.
